# Bounded Context Class Diagrams

This folder keeps the same PlantUML style used by `docs/class-diagram.puml`, but splits the model by bounded context so each diagram can be rendered and reviewed independently.

- `identity-access-class-diagram.puml`: account, user, role, and permission management.
- `asset-management-class-diagram.puml`: assets, gateways, IoT devices, ranges, and operational parameters.
- `monitoring-class-diagram.puml`: dashboards, readings, offline sync, and monitoring components.
- `alerts-class-diagram.puml`: incident generation, notification delivery, escalation, and response lifecycle.
- `maintenance-management-class-diagram.puml`: preventive maintenance and technical service tracking.
- `reports-class-diagram.puml`: daily logs, history, compliance, findings, evidence, and exports.
- `shared-class-diagram.puml`: shared infrastructure, layout, language switcher, pagination, router, i18n, and app shell.
